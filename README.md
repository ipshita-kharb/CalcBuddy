🧮 CalcBuddy 🧮
- A beginner C++ console calculator that performs continuous arithmetic operations (+, -, *, /) using loop-based logic, allowing users to chain calculations and control execution flow interactively.

⚙️Features
- Supports basic arithmetic operations: +, -, *, /
- Continuous calculation (chaining results)
- User-controlled execution flow (continue or exit)
- Input validation for invalid operators
- Protection against division by zero
- Simple and interactive command-line interface

🛠️How It Works
- User enters the first number
- Chooses an arithmetic operator
- Enters the next number
- The result is updated continuously
- User can continue calculations or exit anytime

- Conditional statements in C++
- State management using variables
- Input validation and error handling
- Building interactive CLI applications
